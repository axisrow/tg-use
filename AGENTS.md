# Правила кода для агентов (tg-use)

Дисциплина — ponytail: ленивый к решению, не к чтению. Перед каждой строкой
своего кода пройти лестницу сверху и остановиться на первой ступени, которая
держит:

1. Это вообще нужно? Гипотетическая потребность = не писать.
2. Уже есть в кодовой базе? Сначала прочитай затрагиваемый код, потом
   переиспользуй — не переизобретай то, что лежит в соседнем файле.
3. Умеет stdlib?
4. Умеет нативная платформа?
5. Уже умеет browser-use (навигация, ожидания, чтение DOM — его зона)?
6. Можно одной строкой?
7. Только теперь — минимум, который работает.

Валидацию, обработку ошибок и безопасность не упрощать.

## Безопасность эпика

- Темп: 2–3 c между действиями в чате.
- Только диалоги с ботами. Ни одного сообщения живым людям.
- Каталог `~/.tg-agent-profile` = пароль: полный доступ к аккаунту. Не
  коммитить, не копировать, не чистить.

## Архитектура

- Единственная runtime-зависимость — browser-use; всё остальное — stdlib.
- `tg-use.py` — весь CLI, один файл. `ask()` — единственный мост к браузеру,
  один `ask` = один прогон агента.
- Свой код — только каркас CLI (argparse), конфиг Browser/LLM и логика обхода/
  сценариев/артефактов. Абстракций «на будущее», обёрток над browser-use и
  конфиг-фреймворков не заводить.
